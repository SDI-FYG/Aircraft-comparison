1
Run the Python script

Open a terminal and run flyinggroup_research_v7_2.py. Click Search All Aircraft. Wait for it to finish (typically 10–20 minutes). When done, click Save CSV — or find the auto-saved files in Documents/FLYINGGROUPResearch/.

2
Convert the CSV to JSON

Open a terminal in the folder containing the CSV and run:

python3 -c "
import csv, json, sys
with open(sys.argv[1], encoding='utf-8') as f:
    rows = list(csv.DictReader(f))
# Map CSV columns → Market tab fields
out = []
for r in rows:
    reg = r.get('reg','')
    if reg.startswith('N'):         reg_type = 'N-reg'
    elif reg.startswith('OE') or reg.startswith('D-') or reg.startswith('F-') \
      or reg.startswith('G-') or reg.startswith('HB-') or reg.startswith('OY-') \
      or reg.startswith('SE-') or reg.startswith('LN-') or reg.startswith('OO-') \
      or reg.startswith('CS-') or reg.startswith('EC-') or reg.startswith('I-') \
      or reg.startswith('PH-') or reg.startswith('SP-') or reg.startswith('OK-'): reg_type = 'EASA'
    else:                            reg_type = reg or '—'
    out.append({
        'type':     r.get('subtype') or r.get('model','—'),
        'yom':      r.get('yom','—'),
        'ttaf':     r.get('ttaf','—'),
        'price':    r.get('price','Upon request'),
        'location': r.get('location','—'),
        'reg_type': reg_type,
        'url':      r.get('url',''),
        'source':   r.get('source',''),
        'serial':   r.get('serial','—'),
        'seller':   r.get('seller','—'),
    })
print(json.dumps(out, indent=2))
" market_research_YYYYMMDD_HHMM.csv > market_data.json

Replace market_research_YYYYMMDD_HHMM.csv with the actual filename from step 1.

3
Open this HTML file in a text editor

Right-click the HTML file → Open with → any plain text editor (Notepad, TextEdit, VS Code, Notepad++). Do not use Word.

4
Find the data block — use Ctrl+F / Cmd+F to search for: 
/* ═══ PASTE MARKET DATA HERE ═══ */

You will see two lines like this. Select everything between them (the existing JSON array, including the [ and ] brackets) and delete it.

5
Paste the new data and update the date

Paste the contents of market_data.json in place of what you deleted. Then update the date on the line just above:

const MARKET_UPDATED = "2026-05-18"; // ← change this date
6
Save and share

Save the file. Send it to colleagues by email or put it on a shared drive. They open it in any browser — no internet connection required for viewing.

✓ That's it. The Market tab will show the updated listings automatically.
